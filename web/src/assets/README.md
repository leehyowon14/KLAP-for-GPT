# UI assets

## KLAP logo

`klap-logo.svg` combines the original `KLAP-Sparks.svg` and `KLAP-Mark.svg` layers
from `../KLAP_mac/KLAP.icon/Assets`, in the same order as `KLAP.icon/icon.json`.
The original paths, viewport, and fills are preserved on a transparent background.
The mark is the existing KLAP brand, not a Toss asset.

## Tossface

commit `37720aa5cf2ec9a853a9787f29e39002c58cc2e7`.
Copyright: Toss team (Viva Republica). See `tossface/LICENSE.txt` for the complete
Tossface license and https://toss.im/tossface/copyright for the copyright notice.
Files are bundled unchanged; only their local filenames identify their UI role.
No CDN or font download is required at runtime.
